# Mazmorras y Café - Sitio Web Oficial

## Contenido del paquete
- `index.html`: Aplicación web completa (responsive para PC y celular) con catálogo de juegos, carta de cafetería, reserva de turnos y modo edición en vivo.

## Cómo usar
1. Descomprimí el archivo `.zip` en una carpeta.
2. Hacé doble clic en `index.html` para abrirlo en cualquier navegador (Chrome, Edge, Safari, Firefox) o subilo directamente a **GitHub Pages**, **Netlify** o **Vercel**.
3. Usá el botón **"✏️ Editar Precios / Datos"** en la barra superior para cambiar precios, textos, agregar juegos o actualizar tu número de WhatsApp y dirección. Los cambios se guardan automáticamente en el navegador.
